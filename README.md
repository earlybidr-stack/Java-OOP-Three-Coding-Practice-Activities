# Java-OOP-Three-Coding-Practice-Activities

Activities 1 through 3 focus on core object-oriented programming principles in Java by modeling real-world campus systems—a printing account, a lab grade record, and a digital wallet. Across these exercises, you will practice encapsulating private instance variables, overloading and chaining constructors, and implementing strict input validation to safeguard object state. Together, the three tasks build a solid foundation in designing reliable, self-contained classes whose behavior is verified through ordered test cases.
